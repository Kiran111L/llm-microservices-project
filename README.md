# llm-microservices-project
This project demonstrates the full pipeline of abstractive text summarization — from data preprocessing, Seq2Seq model training, and model saving.


This project is a Text Summarization System that automatically generates concise summaries from long input text (like news articles).
It uses a Sequence-to-Sequence (Seq2Seq) deep learning model with Encoder-Decoder architecture (based on LSTMs/GRUs or Transformer concepts).
The project is deployed as a Flask web API, so it can be integrated with any frontend or tested using Postman.
